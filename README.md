## dev guide

theme is located in `./src`</br>
</br>
Start:

```bash
# Start
docker compose up --remove-orphans

 # Stop 
docker compose down

# Restart
docker compose restart
```

## requirements

- docker
- vs code sass watch extension
- acf pro (full version found on github for free)
- `composer require squizlabs/php_codesniffer --dev`
